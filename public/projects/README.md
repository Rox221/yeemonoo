# Project screenshots

Drop real screenshots here using these exact filenames — each project in
`src/data/portfolioData.js` already points at its path via `image`, so the
placeholder composition (browser chrome / phone frame / terminal / diagram)
swaps out for the real image automatically once the file exists. No code
changes needed.

| File | Project | Suggested shot |
| --- | --- | --- |
| `project-one.png` | Project One | Full page / dashboard, top of the fold |
| `project-two.png` | Project Two | A single app screen, portrait, cropped tight to the device content |
| `project-three.png` | Project Three | Terminal/CLI output or a code editor pane |
| `project-four.png` | Project Four | Architecture diagram, or a dashboard/monitoring screenshot |

Tips:
- Export at 2x for retina screens (e.g. ~1600px wide for the browser/plate
  shots, ~800px wide for the device shot).
- Crop tightly — the frames crop with `object-cover`, so lead with the most
  interesting part of the screen.
